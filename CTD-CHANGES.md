# CTD OBS changes from OBS Studio

CTD OBS is based on [OBS Studio](https://github.com/obsproject/obs-studio) and stays under the GPL. Every change to
OBS's own behaviour is listed here, so merging a new OBS release stays manageable.

Base: OBS Studio 33.0.1.

## Not changed yet

- Other languages still say OBS.
- Linux branding and packaging (Linux plugin folders are CTD OBS's own, `docs/ctd/plugins.md`).
- macOS: no virtual camera (needs a system extension provisioning profile, `docs/ctd/macos-signing.md`).
- NDI: the NDI library isn't bundled until Vizrt and CTD's legal call clear it for a GPL app (`CTD_NDI_BUNDLED`,
  `docs/ctd/ndi.md`); no NDI PTZ, tally or NDI|HX-specific options.
