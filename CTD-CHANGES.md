# CTD OBS changes from OBS Studio

CTD OBS is based on [OBS Studio](https://github.com/obsproject/obs-studio) and stays under the GPL. Every change to
OBS's own behaviour is listed here, so merging a new OBS release stays manageable.

Base: OBS Studio 33.0.1.

| Area | What changed | Where |
|---|---|---|
| Config | `ctd-obs` folder instead of `obs-studio` for settings, scenes, logs, plugins and the shader cache | `frontend/` paths, `libobs-d3d11/d3d11-subsystem.cpp`, `libobs-d3d11/d3d11-shader.cpp` |
| Running beside OBS | Its own single-instance check | `frontend/utility/platform-windows.cpp` |
| Settings ▸ CTD | A CTD page at the end of Settings: the CTD plugin's section (CTD Relay address, pairing, profile, WebSocket sharing, Feed servers…; `ctd_settings_widget`), Vertical (opens the vertical canvas's own settings window through its dock's gear button) and Advanced (Plugin Manager, Scripts, WebSocket Server Settings, opened once Settings closes). CTD ▸ CTD Settings… opens it. The docks keep status and show actions | new `frontend/ctd/ctd-settings-page.cpp`, `frontend/settings/OBSBasicSettings.cpp`, `frontend/settings/OBSBasicSettings.hpp`, `frontend/ctd/ctd-menu.cpp`, `frontend/widgets/OBSBasic.hpp`, `frontend/cmake/ctd-show.cmake`, `frontend/data/locale/en-US.ini` |

## Not changed yet

- Other languages still say OBS.
- Linux paths and branding.
- macOS: no virtual camera (needs a system extension provisioning profile, `docs/ctd/macos-signing.md`).
